# BuDu

แอปสะสมแต้มความดีสำหรับ 2 คน · PWA สำหรับ iPhone · HTML/CSS/JS ล้วน ไม่มีขั้นตอน build

- ทดสอบบนเครื่อง: `python -m http.server 5173` แล้วเปิด http://localhost:5173
- ข้อมูลอยู่บน Supabase · **แพ็กเกจฟรีจะพักโปรเจกต์เมื่อไม่มีใครใช้เกิน 1 สัปดาห์** ถ้าแอปเปิดไม่ติดหลังหยุดใช้นาน ให้เข้าเว็บ Supabase แล้วกด Restore project
- อัปเดตไฟล์แล้วต้องเปลี่ยนเลข `CACHE` ใน `sw.js` ทุกครั้ง
